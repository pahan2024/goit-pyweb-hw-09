# Домашнє завдання #9. Скрапінг веб-сайтів за допомогою Scrapy (MongoDB)

Цей проєкт реалізує автоматичний збір (скрапінг) даних з сайту [http://toscrape.com](http://toscrape.com) та їх подальше збереження у хмарну базу даних MongoDB Atlas.

## 🛠️ Технологічний стек
* **Фреймворк скрапінгу:** Scrapy (версії 2+)
* **База даних:** MongoDB Atlas (Cloud)
* **ODM/Драйвери:** `mongoengine`, `python-dotenv`, `certifi`

---

## 🗂️ Структура проєкту
* `spiders.py` — логіка павука Scrapy, який обходить усі сторінки сайту та збирає інформацію про цитати й авторів.
* `main.py` — єдина точка входу (скрипт) для запуску краулера та збереження результатів у JSON-файли.
* `seed.py` — скрипт для очищення хмари та імпорту отриманих даних у колекції MongoDB Atlas.
* `db.py` / `models.py` — налаштування підключення та описи моделей даних (`Author`, `Quote`).

---

## 🚀 Як запустити проєкт локально

### 1. Встановлення залежностей
Встановіть необхідні бібліотеки через термінал:
```bash
pip install scrapy mongoengine python-dotenv certifi
```

### 2. Налаштування файлу `.env`
Створіть файл `.env` у корені проєкту та вкажіть ваш рядок підключення до MongoDB Atlas:
```env
MONGO_URI=mongodb+srv://paulyskorbin_db_user:ВАШ_ПАРОЛЬ@cluster0.zvtlk95.mongodb.net/homework8?retryWrites=true&w=majority
```

### 3. Скрапінг сайту
Запустіть єдиний скрипт для запуску павука Scrapy. Він обійде весь сайт і автоматично створить два файли `quotes.json` та `authors.json`:
```bash
python main.py
```

### 4. Імпорт даних у хмару
Запустіть завантаження щойно зібраних даних у MongoDB Atlas:
```bash
python seed.py
```

## 📌 Перевірка сумісності
Оскільки структура отриманих файлів `quotes.json` та `authors.json` повністю збігається з вимогами попереднього домашнього завдання, пошукова CLI-програма (`search.py` з ДЗ №8) буде коректно та без змін працювати з новою наповненою базою даних.
